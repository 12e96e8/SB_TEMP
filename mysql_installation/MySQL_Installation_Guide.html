Windows MySQL 8.4 LTS
完整安裝與測試教學

從官方下載、安裝資料庫服務、設定 MySQL Workbench，到 Node.js Express + mysql2 的連線測試。適用 Windows 10 / 11（64 位元）與 React + Socket.IO 專題。

MySQL Community ServerMySQL WorkbenchNode.js · Express · mysql2
01　MySQL Server真正儲存資料的服務，預設 Port 3306
02　MySQL Workbench圖形化管理介面，需另外安裝
03　mysql2（npm）讓 Node.js Express 存取資料庫

01 開始之前

  • 確認 Windows 為 64 位元，並使用具備安裝權限的 Windows 帳號。
  • 確認已安裝 Microsoft Visual C++ Redistributable（缺少時依安裝提示補裝）。
  • 若以前安裝過 MySQL 5.7、8.0 或其他版本，先確認 Port 3306 是否被占用。
  • 學習階段不建議開放 MySQL 3306 到公網；外部使用者應透過 Node.js API 存取。

官方下載連結

  • MySQL Community Server
  • MySQL Workbench
  • MySQL 8.4 Windows 安裝文件
MySQL Installer 8.0 與 MySQL Server 8.4 MSI 的安裝流程不同。安裝 8.4 時，請從 Community Server 下載頁選擇 Windows MSI。

02 下載與安裝 MySQL Server

  1. 前往 Community Server 官方下載頁，選擇 MySQL 8.4 LTS。
  2. 作業系統選 Microsoft Windows，下載 Windows x86-64 MSI Installer（例如 mysql-community-8.4.x.msi）。
  3. 如出現 Oracle 帳號登入選項，可按 No thanks, just start my download 跳過。Community Server 無需購買授權。
  4. 雙擊 MSI，依安裝精靈按 Next / Install，視情況提供系統管理員權限。
  5. 完成後啟動隨附的 MySQL Configurator；未完成組態時，Server 可能尚未啟動。

03 MySQL Configurator 設定

不同安裝版本的畫面可能略有差異，依下列原則設定。

設定項目建議值或操作
伺服器類型一般開發用途採預設開發／電腦配置選項
TCP/IP啟用；Port 設為 3306（占用則調整並記錄）
外部存取本機開發不需開放公網防火牆 3306
驗證使用 8.4 預設支援的安全驗證方式
root 密碼設定強密碼，妥善保存，不放進 Git
Windows Service建立服務，名稱可能為 MySQL84
Startup可選隨 Windows 自動啟動
Apply / Execute確認每個步驟完成，沒有 Failed
首次管理連線建議：Host 127.0.0.1、Port 3306、User root、Password 為安裝時設定的密碼。

確認 Windows 服務

PowerShell 
Get-Service *mysql*

若狀態是 Running，代表服務正在執行。若為 Stopped，可在系統管理員 PowerShell 執行（服務名稱請以實際查詢結果為準）：

PowerShell（系統管理員） 
Start-Service MySQL84

確認版本（可選）

PowerShell 
& "C:\Program Files\MySQL\MySQL Server 8.4\bin\mysql.exe" --version

PowerShell 執行帶有空白的程式路徑時，需在前面加上 & 執行運算子。

04 安裝 MySQL Workbench

  1. 前往 Workbench 官方下載頁。
  2. 下載 Windows 對應的 MSI；Workbench 版本號不必與 Server 8.4 完全相同。
  3. 執行 MSI，依提示安裝必要的 Microsoft 執行階段元件。
  4. 從 Windows 開始選單搜尋並開啟 MySQL Workbench。

建立本機資料庫連線

點選 Test Connection；成功後按 OK。雙擊連線即可進入 SQL Editor。

05 建立專題資料庫

在 Workbench 開啟新 SQL 分頁，貼上並執行以下 SQL：

SQL 
CREATE DATABASE IF NOT EXISTS competition_db
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;

USE competition_db;

CREATE TABLE IF NOT EXISTS players (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  nickname VARCHAR(50) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id)
);

INSERT INTO players (nickname) VALUES ('test_user');

SELECT * FROM players;

按 Workbench 的 閃電按鈕 執行。如果能查到 test_user，就完成資料庫的建立、寫入與讀取測試。

06 建立 Node.js 專用資料庫帳號

正式專案不要以 root 作為 API 帳號。這裡建立只存取指定資料庫的低權限帳號；請替換範例密碼。

SQL 
CREATE USER IF NOT EXISTS 'competition_app'@'localhost'
  IDENTIFIED BY 'CHANGE_THIS_TO_A_STRONG_PASSWORD';

GRANT SELECT, INSERT, UPDATE, DELETE
ON competition_db.* TO 'competition_app'@'localhost';
此帳號未授予 CREATE、DROP 等資料表結構變更權限。若需要 migration，應另使用有必要權限的管理帳號。當 Node.js 的 Host 設為 127.0.0.1 時，需依實際 MySQL 主機匹配設定確認帳號是否可連線；必要時另建相應帳號，不要直接開放 %。

07 Node.js + Express + mysql2 測試

步驟 A：安裝 npm 套件

Terminal 
cd backend
npm install express mysql2 dotenv

步驟 B：在 backend 建立 .env

.env 
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=competition_app
DB_PASSWORD=CHANGE_THIS_TO_A_STRONG_PASSWORD
DB_NAME=competition_db
PORT=3001
將 .env 加入 .gitignore。切勿將 root 或應用程式帳密上傳至 GitHub。

步驟 C：建立 server.mjs

JavaScript · server.mjs 
import 'dotenv/config';
import express from 'express';
import mysql from 'mysql2/promise';

const app = express();
const pool = mysql.createPool({
  host: process.env.DB_HOST,
  port: Number(process.env.DB_PORT),
  user: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
  database: process.env.DB_NAME,
});

app.get('/api/players', async (req, res) => {
  try {
    const [rows] = await pool.query('SELECT * FROM players');
    res.json(rows);
  } catch (err) {
    console.error(err);
    res.status(500).json({ error: 'Database query failed' });
  }
});

app.listen(Number(process.env.PORT || 3001), () => {
  console.log('API listening on port 3001');
});

08 啟動並驗證

Terminal 
node server.mjs

在瀏覽器開啟 http://localhost:3001/api/players。

預期看到包含 id、nickname、created_at 的 JSON 陣列，且 nickname 為 test_user。

React 呼叫範例（Vite Proxy）

假設 Vite 已設定將 /api 轉送到 localhost:3001：

JavaScript 
const response = await fetch('/api/players');
const players = await response.json();
console.log(players);

搭配 Cloudflare Tunnel 時

  • MySQL 保留在自己的 Windows 電腦上，由 Node.js 在本機連線。
  • React 與 Node.js 可分別啟動，用 Vite Proxy 將 /api 轉送到 3001。
  • Cloudflare Quick Tunnel 可指向 React 的 localhost:5173，不要公開 MySQL 3306。
  • 外部朋友透過公開網址存取 React，React 再向 API 請求資料。

09 問題排查

狀況檢查方式
Workbench 連不上確認服務 Running、Port 3306、Host 與 root 密碼
Port 3306 已占用使用下方 netstat 指令檢查
mysql 不是命令使用 mysql.exe 完整路徑或設定 PATH
Access denied檢查帳號、密碼、Host 與 GRANT 權限
ECONNREFUSED通常是服務未啟動或 Host、Port 不正確
Node.js SQL 查不到資料先在 Workbench 執行 SELECT，確認 database 與表名
PowerShell 
netstat -ano | findstr :3306
